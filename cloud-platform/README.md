# ACEpresso Student Portal – testing
This is a **test deployment** for the 3HFIT ACEpresso 21-day student portal.
Student registration requires a unique, one-time invitation code generated by an authenticated admin.
The website, teaching content, and frontend code live on a public repository; this branch is NOT a secure way of keeping teaching materials confidential.
Configure ACE_DB_PATH=/data/acepresso.sqlite3, ACE_HTTPS=1, ACE_ADMIN_LOGIN and ACE_ADMIN_PASSWORD in the deployment environment and attach a persistent volume mounted to /data.
On first boot an admin account is created only if no admin exists. Change the password using POST /api/change-password after login.
Admin /manage, leader /teacher, students /study. Do not use with real personal data before security, backups, and Chinese mainland connectivity have been reviewed.
