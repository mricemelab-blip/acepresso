# ACEpresso V5 | 学员端教学体验
独立于仓库现有教材、首页与其他系统，入口源代码为 [index.html](./index.html)。

## 学员体验
- 登录后默认进入今日六项任务；侧栏仅保留今日学习、21天路径、学习小组、学习档案。
- 九章教材从原始合订本提取的 HTML 内容，按需在对应任务展开。
- 每天10张复习卡，共210张，逐张记录掌握与待复习状态。
- 21个每日连续情境、63道独立决策题，四位客户轮流推进；每道题含客户原话、已知信息、答题结构、参考话术和组长评分要点。
- 组长批改过渡流程：学员下载当天 HTML 批改包，组长给三题分别打分并导出反馈 JSON，学员在学习档案导入。
- 任务完成后生成日学习卡 PNG；全程支持本机记录备份与恢复。

## 内容与安全边界
原教材为《ACEpresso教辅合订本 V4.1》；V5 新增案例及参考答案属于教学审核稿，发布给正式班级前需教研终审，尤其是筛查、转介和特殊健康状况。
此网页为本机数据演示；没有真实账号验证、云端同步、组内共享与自动提交。不要将昵称登录视为访问权限控制，也不要在演示版录入真实客户健康资料。
GitHub 源代码入库不等于 GitHub Pages 已启用；中国大陆学员的正式托管与账号/数据后台仍需独立配置。

## 来源与顺序
保持原21天课程节奏；Day4为Ch2行为改变复习，Day18只整合已学习Ch1–6；Day19进入Ch7–9；Day20–21全课程复盘。
